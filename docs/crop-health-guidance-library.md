# Crop-health guidance library

## What users see

Crop-health reports include a short, deterministic **Safe next steps** panel beside the experimental maize image-screening candidates. It is returned by the FastAPI report API and appears in both the farmer report and authorized reviewer view. Existing reports receive the same panel when read; no database migration is required. The text is not generated by the image model or an LLM.

The guidance asks the farmer to compare a model candidate with the plant and field context, record when and where the issue is changing, keep follow-up photos, and seek CropPulse reviewer or local extension input. A model class is only mapped to an EPPO identity link when the class is explicitly known. EPPO is used for names and identity reference, not for a diagnosis or a Rwanda treatment recommendation.

## Treatment and safety boundary

CropPulse does not recommend a pesticide, medicine, active ingredient, dose, or spray schedule from a photograph. Do not treat from a model label. A qualified local crop-protection professional should confirm the issue and check current Rwanda registration and the product label before pesticide use. No Rwanda product registry was confirmed as current during this work, so the interface intentionally does not name products.

FAO's IPM page supports general principles such as monitoring, considering non-chemical approaches, and adapting choices to local conditions. It expressly cautions against one-size-fits-all advice. CropPulse paraphrases these high-level principles and links to the source; this is not a disease-specific recipe. [FAO: How to practice IPM](https://www.fao.org/agriculture/crops/thematic-sitemap/theme/spi/scpi-home/managing-ecosystems/integrated-pest-management/ipm-how/en/).

## Sources, attribution, and reuse

| Source | Use in CropPulse | Limits |
| --- | --- | --- |
| [FAO IPM guidance](https://www.fao.org/agriculture/crops/thematic-sitemap/theme/spi/scpi-home/managing-ecosystems/integrated-pest-management/ipm-how/en/) | General monitoring, local tailoring, and IPM principles | Not a Rwanda maize-specific treatment guide |
| [CABI PlantwisePlus Knowledge Bank](https://plantwiseplusknowledgebank.org/) | Link users to country-specific information | CABI's official factsheets listing identifies a Rwanda country pack. We link out and do not copy factsheet text or images; verify CABI terms and any permission before incorporating content into CropPulse |
| [RAB](https://www.rab.gov.rw/) | Local extension/research referral link | Its site timed out during source review; no RAB disease-specific claim is included |
| [EPPO Global Database](https://gd.eppo.int/) | Taxonomic identity and common-name links for three model labels | EPPO content is not a local diagnosis or treatment recommendation; source-site reuse terms apply |

Disease identity mappings are limited to model class names already present in the bundled manifest: grey leaf spot → *Cercospora zeae-maydis* (EPPO CERCZM); common rust → *Puccinia sorghi* (PUCCSO); northern leaf blight → *Exserohilum turcicum* (SETOTU). A `healthy` candidate is explicitly not a finding that the plant has no problem. Unknown class names receive no fabricated identity.

The library stores original concise UI wording and source links, not copied source factsheets. URLs and the PlantwisePlus country-pack listing were checked on 21 October 2026. Recheck availability, scope, and terms before each release. The internal guidance version is in `backend/crop_health_guidance.py`.

## Geographic coverage and known limits

This is a Rwanda-facing workflow, but its general IPM wording has not been locally validated by RAB or a Rwanda crop-protection specialist. There is no district-specific treatment dataset. Model screening remains experimental and maize-only; it is based on PlantVillage classes and cannot confirm a disease from a Rwanda field photo. Reviewers on CropPulse are not represented as certified agronomists. The source list is a starting point for an expert-reviewed knowledge base, not a substitute for one.

Before adding disease-specific control steps or chemical products, obtain current Rwanda-specific sources, permissions/licensing, independent expert review, the competent authority's current registration information and label constraints, and a revision/expiry process. Add bilingual (English/Kinyarwanda) reviewed wording before presenting operational guidance to farmers.
