### Database configuration and initialization

`backend/db.py::database_url()` returns `CROP_PULSE_DATABASE_URL` when set; otherwise it returns `sqlite:///./data/croppulse_phase1.sqlite3`. Relative SQLite paths resolve from the process working directory. SQLAlchemy engine creation in `get_engine()` is lazy. Its SQLite connect hook enables foreign-key enforcement; that pragma is connection-local and does not create tables.

`backend/api.py` creates the FastAPI app and registers routes at import. Its lifespan validates runtime settings and calls `Base.metadata.create_all()` only when `CROP_PULSE_AUTO_CREATE_SCHEMA` is exactly `1`. The proposed isolated launch explicitly sets it to `0`; it does not run migrations. A read-only SQLite URI will also prevent application writes during the limited preflight.

The API module was imported with bytecode writing disabled. It resolved to this project's `backend/api.py`; the SQLAlchemy engine cache still had zero entries after import. The import did create the app object but did not initialize the database engine. Source inspection shows the model loader is lazy and email is not sent by import. This supports the conclusion that the import itself does not create tables or write to the database.

## Import and preflight behavior

The SQLAlchemy `SELECT 1` check is read-only. The verified URI included `mode=ro`; `PRAGMA database_list`, reading `alembic_version`, `PRAGMA integrity_check`, and `PRAGMA foreign_key_check` do not write. The current `backend.api` import was run with `PYTHONDONTWRITEBYTECODE=1`, test environment mode and auto-create disabled; it resolved to the intended module and did not instantiate the SQLAlchemy engine.

The proposed script below performs all identity and database checks before calling `uvicorn.run`. It builds the SQLAlchemy URL in read-only mode and uses the same imported API module and cached engine for the server process. It prints no secret and selects no personal records. It binds only to loopback port `18001`. If the exact path, schema head, integrity, engine target, code path or runtime path check fails, Python raises before the server starts.

## Proposed controlled launch commands — not executed

**A separate explicit launch approval is required before running this sequence.** It does not restart or replace the existing listeners. Run in PowerShell from the project root. The database path is deliberately pinned to the verified synthetic test file; changing it requires repeating the preflight and approval. The SQLite connection is forced read-only.

```powershell
$root = 'C:\xampp\htdocs\croppulse-rwanda (4)\croppulse-rwanda'
$python = Join-Path $root '.venv\Scripts\python.exe'
$approvedDb = 'C:\xampp\htdocs\croppulse-rwanda (4)\croppulse-rwanda\.test-runtime\phase4-recovery-3f5e0732384149d7b6201b3677958bc4\isolated-test.sqlite3'
$port = 18001

Set-Location -LiteralPath $root
if ((Resolve-Path -LiteralPath (Get-Location).Path).Path -ne $root) { throw 'Unexpected working directory.' }
if (-not (Test-Path -LiteralPath $python -PathType Leaf)) { throw 'Project virtual-environment Python is missing.' }
if (-not (Test-Path -LiteralPath $approvedDb -PathType Leaf)) { throw 'Approved isolated database is missing.' }
if (Get-NetTCPConnection -State Listen -LocalPort $port -ErrorAction SilentlyContinue) { throw 'Test port is occupied.' }

$code = @'
import os, sys, secrets
from pathlib import Path
from sqlalchemy import create_engine, text
from sqlalchemy.engine import URL

root = Path(r'C:\xampp\htdocs\croppulse-rwanda (4)\croppulse-rwanda').resolve(strict=True)
approved = Path(r'C:\xampp\htdocs\croppulse-rwanda (4)\croppulse-rwanda\.test-runtime\phase4-recovery-3f5e0732384149d7b6201b3677958bc4\isolated-test.sqlite3').resolve(strict=True)
candidate = (root / 'data' / 'croppulse_phase1.sqlite3').resolve()
expected_python = (root / '.venv' / 'Scripts' / 'python.exe').resolve()
if Path(sys.executable).resolve() != expected_python: raise SystemExit('Wrong Python executable.')
if Path.cwd().resolve() != root: raise SystemExit('Wrong working directory.')
if approved == candidate or not approved.is_file(): raise SystemExit('Database is not the approved isolated test file.')

os.environ['CROP_PULSE_ENVIRONMENT'] = 'test'
os.environ['CROP_PULSE_AUTO_CREATE_SCHEMA'] = '0'
os.environ['CROP_PULSE_SECRET_KEY'] = secrets.token_urlsafe(48)  # process-local; never printed or persisted
readonly_url = URL.create('sqlite+pysqlite', database=f'file:{approved.as_posix()}', query={'mode': 'ro', 'uri': 'true'}).render_as_string(hide_password=True)
os.environ['CROP_PULSE_DATABASE_URL'] = readonly_url

import backend.api as api
from backend.db import get_engine
module_path = Path(api.__file__).resolve()
if module_path != (root / 'backend' / 'api.py').resolve(): raise SystemExit('Imported API module is outside the approved project.')
engine = get_engine()
if engine.dialect.name != 'sqlite': raise SystemExit('Unexpected database dialect.')
with engine.connect() as connection:
    opened = Path(connection.execute(text('PRAGMA database_list')).one()[2]).resolve(strict=True)
    if opened != approved: raise SystemExit('Engine opened a different SQLite file.')
    revision = connection.execute(text('SELECT version_num FROM alembic_version')).scalar_one()
    integrity = connection.execute(text('PRAGMA integrity_check')).scalar_one()
    fk_violations = len(connection.execute(text('PRAGMA foreign_key_check')).fetchall())
    if revision != '0015_weather_alert_foundation': raise SystemExit('Database revision is incompatible.')
    if integrity != 'ok' or fk_violations != 0: raise SystemExit('Database integrity preflight failed.')
    if connection.execute(text('SELECT 1')).scalar_one() != 1: raise SystemExit('Read-only connection preflight failed.')

print('test_pid:', os.getpid())
print('python:', Path(sys.executable).resolve())
print('cwd:', Path.cwd().resolve())
print('api_module:', module_path)
print('database:', opened)
print('revision:', revision)
print('integrity:', integrity)
print('foreign_key_violations:', fk_violations)
print('server: starting on 127.0.0.1:18001; database URI is read-only')
import uvicorn
uvicorn.run(api.app, host='127.0.0.1', port=18001, access_log=False)
'@

& $python -B -c $code
```

The server launch is last in the script; all checks abort before it on failure. Only health and OpenAPI GET requests should be used during this preflight. Do not send login, registration, mutation, or authenticated workflow requests. Do not route users or frontend traffic to port 18001.
